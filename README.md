# Compte Rendu : Injection des Dépendances (IoC)
**Réalisé par :** Oussama Boustane

## Introduction
Ce dépôt contient l'implémentation du TP sur l'Inversion de Contrôle et l'Injection des Dépendances, basé sur l'exemple traité en cours. L'objectif est de montrer l'évolution d'une application utilisant un couplage fort vers un couplage faible grâce à l'IoC.
